# Question-local uncertainty map: updated after quantitative execution

q_488429beed204371. This map is an analytical guide, not a causal model fitted to the data.

PMP22 start-associated response
  |
  +-- Shared P1/P2 multiplicative response, stable relative composition
  |     SOX10: contradicted descriptively by relative P1 loss across all frozen sensitivity variants.
  |     cAMP: modest full-sample difference, but an invariant ratio is not reliably excluded at donor level.
  |
  +-- Different response magnitude while both signals co-move
  |     SOX10: strongest supported measured-RNA pattern; not gene-only selectivity.
  |     cAMP: both co-induced; preferential P1 induction is a fragile descriptive estimate.
  |     Measurement: within-library log ratio and P1/(P1+P2), separate from RPM differences.
  |
  +-- Apparent selectivity caused by low signal / boundary / single clone
  |     cAMP: one zero-baseline library materially affects interpretation; combined sensitivities reverse sign.
  |     SOX10: effect survives positional windows, low-signal handling, each removal and both label families.
  |     Still unresolved: technical capture bias, clonal adaptation and parental control-clone mismatch.
  |
  +-- Shared Schwann-cell program versus PMP22-only action
  |     Measured Mpz/Mbp and context signals also change; SOX10 is not a selective PMP22-only perturbation.
  |     Within-gene P1/P2 redistribution can be hidden by the P2-dominated selected total.
  |     Mouse enhancer deletion with first-exon RNA and Mag/Mpz controls is separate mechanistic support,
  |     not proof that rat cAMP or SOX10 perturbations work through that enhancer.
  |
  +-- Initiation versus RNA survival / maturation / composition
  |     Unresolved. Tn5Prime total-RNA starts and first-exon qPCR are not nascent initiation.
  |     Discriminator: calibrated promoter-resolved nascent plus mature RNA and survival in same units.
  |
  +-- Generalization / replication
        Same native/workbook values = same experiment, not replication.
        Thesis and final mouse publication = one experiment lineage.
        Rat 48-h SOX10 siRNA = separate experiment supporting co-decrease, not numeric differential replication.
        Mouse enhancer deletion = independent in-vivo cis context, age dependent.
        cAMP-sensitive reporter PMID10806367 = independent cis plausibility, not endogenous RNA contrast.
        PDE4D-inhibitor PMID39823724 = context-dependent gene-selectivity lead for peer, not P1/P2 validation.
        Next question: donor/lot-split primary cultures above P1 low signal, and truly crossed treatments
        if cAMP-by-SOX10 interaction is the aim.
