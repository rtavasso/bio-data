Compared feasible sources before substantial acquisition
1. Gerber2021 SNAT (PMC8064760; GSE137870 superseries; GSE138577 10x subseries): directly cited by Nae1 Figure1C-E. Supplement1 contains full RPKM tables for endoneurium-enriched E13.5/E17.5/P1/P5/P14/P24/P60 nerves (four independent samples/stage, two/sex; embryonic pools, postnatal single mice) AND P5 FACS fractions allSC, mSC-enriched and nmSC-enriched (four mouse-derived samples/gate, sex balanced). Strongest first choice: same species and neonatal context, same-age purified state contrast plus time series. Fractions are enriched, not pure categorical identities; sample-pairing across gates must be verified, not invented. mSC/nmSC are states, not independent replicates. Primary text calls the mapper reference GRCh38.p10 despite mice; retain this apparent source typo and use source labels without coordinate analysis. Supplement2 supplies cell labels; 10x P1 matrix has three run IDs whose pooling/sample independence requires inspection. P1 FACS deliberately depletes Schwann cells to approximately 30%; observed cell frequencies CANNOT estimate tissue proportions. Per-type RNA profiles remain potentially useful. Choose processed XLS and P1 annotated matrix, not R/Seurat serializations or author code.
2. GSE177037 inherited purified rat Schwann/whole-nerve crush series: two pooled preparations per compartment/state, P18 and 0/3/5/7 days. Useful incidental test of repair-state effects and whether a whole-nerve program appears in purified cells. Different species, age and injury; not a neonatal developmental reference, no donor pairing assumed. Exact inherited logCPM artifact usable for purified samples; full native counts needed for whole-nerve comparison and normalization sensitivity.
3. GSE147285, originally mesenchymal paracrine ligand/axon-growth study: actual metadata inspected. Neonatal P3-P4 FACS and P2-P3 bead-treated whole nerves, adult uninjured and injured. Full processed expression files exist; different age, sorting and pooled sample identity confound neonatal comparisons. Less suitable than SNAT for quantitative developmental state or composition attribution; selected ligands alone would be insufficient. Keep as contextual/alternate atlas, not independent age replication. One uninjured representation includes earlier Carr mesenchymal data.
4. GSE182098 adult single-nucleus atlas: actual series metadata inspected, captures morphologically complex myelinating cells, but adult/nuclear versus neonatal/whole-cell mismatch. Series selected processed formats are RDS; do not deserialize. Lower priority than age-matched SNAT, not proof that cell types are absent.
5. PMC12217360 SEMA3B/Remak-bundle study: incidental five-age P0/P7/P14/P28/P60 10x series GSE294160. Large numbers of animals pooled for each age, not independent cell-level replicates. Potential closer P7 whole-cell reference, but age-pooled design and lack of inspected barcode annotations make it weaker for uncertainty than SNAT bulk. Metadata lead acquired from an unverified recalled citation then confirmed against actual title/methods; no results of this study are assumed to equal GSE177037. Reassess if SNAT leaves a discriminating branch feasible.

Primary reference tests and falsifiers
A. P5 nmSC-enriched versus mSC-enriched: report log2 RPKM(+0.1) differences with four samples/group; no paired inference without documented matching. Sensitivity pseudocount 0.01/0.5 and ratio of arithmetic means. All four genes must be present and finite; missing or failed estimates stay unavailable. Weak signal (mean RPKM <1 in both groups) flagged and not reinterpreted as zero. Compare reference antioxidant direction/magnitude with Pmp22 and seven myelin markers (Mpz/Mbp/Mag/Prx/Plp1/Cnp/Mal). A generic immature-state explanation predicts a positive antioxidant change with myelin loss of comparable magnitude. A near-zero/negative purified antioxidant response despite strong myelin loss weakens that simple explanation, not all possible pathological states.
B. Developmental bulk trajectory: preselect P1/P5/P14 adjacent-age contrasts, with whole E17.5-P60 range as sensitivity. Plot full time trajectories and PCA of adequately measured genes, never treat seven time points or genes as biological replicates. Fit per-study broad KO/control response as intercept plus externally measured reference difference vectors, excluding Pmp22 and antioxidant genes from fitting. Primary one-dimensional sorted-state projection; separate P1-vs-P5 and P5-vs-P14 projections, then two-axis joint descriptive projection. Eligible background: unambiguous shared labels, control mean count >=10 in source, reference mean RPKM >=1. Preserve broad genes without annotation keyword gate. Report fit, residuals, orthogonal unexplained broad response and target ranks. Bootstrap reference mouse libraries (not genes) for reference variability; coefficients learned on bulk outcomes are descriptive sensitivity, not a causal correction.
C. State-sufficiency operational check: predicts antioxidant contrast to within 0.5 log2 and leaves source separation <=0.5 log2 across primary reference choices. Residual >1 log2 across reference choices weakens sufficiency of THESE reference axes. Mixed results or poor fit are inconclusive. Thresholds concern model discrepancy, not biological equivalence or significance. Report continuous effects regardless of rule.
D. Existing bulk sensitivity: reproduce native four-gene scores, immune/fibroblast/endothelial/proliferation/immature/myelin scores. Same Figlia controls reused once. Regress scores on genotype and one external state/composition proxy at a time within each study; inspect genotype-proxy correlations, overlap, design rank/condition, leave-one-sample coefficient ranges. No causal interpretation. If near collinearity or missing overlap prevents stable adjustment, report that, not an adjusted-null conclusion. Compare normalization and log-ratios to control/reference-defined stable genes; relative effects cannot establish absolute molecules/cell.
E. Cell composition: source-labelled P1 10x cells grouped by run and cell type; sum native UMIs for pseudobulk profiles, preserve per-run counts, unknown run-to-animal independence. Never call cells biological replicates. Calculate source type-enrichment for the antioxidant panel, Pmp22, and marker controls. Fit illustrative nonnegative RNA mixture weights on non-target cell-identity markers with marker-deletion and run-deletion sensitivities only if reference coverage/scale is defensible. They are RNA-contribution proxies, not measured cell fractions. Test observed marker changes for consistency with a pure mixture explanation. If cross-assay calibration makes quantitative weights indefensible, use within-reference mixture bounds and explicitly record the limit instead of making numbers look like measured proportions.
F. Repair reference: descriptive purified versus whole-nerve state fold changes from GSE177037, preserving pool unit, no cross-compartment pairing assumption, plus broad response concordance. It can show whether state alone in another context creates the signature; cannot identify the source of Nae1 effects.
