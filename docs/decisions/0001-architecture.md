# One catalog, immutable evidence, explicit interpretation

SQLite owns identities, revision pointers, run state and relationships. Immutable SHA-256-addressed files own content. PyArrow writes typed result packages; offline HTML is a disposable view. There is no second database, service, agent harness, model dependency, or distributed queue.

Transport never interprets biology. Inspectors describe structure. Assertions cite exact values. Curation accepts a versioned mapping only after evidence validation. The planner checks operator-specific eligibility and freezes candidates before execution. Workers receive immutable inputs and no catalog connection; the parent owns writes.

History tables reject UPDATE/DELETE. Numbered migration 2 adds conflict-review decisions. Workspace writes are serialized; SQLite transactions remain short. Backups use `Connection.backup()` and verified copies, followed by an actual independent restore test.

The initial repository lacked the JSON inventories and contract files referenced by the handoff. New implementation contracts are clearly labeled as derived artifacts.
